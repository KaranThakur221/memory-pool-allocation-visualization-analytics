# Project details

## Project name

Custom Memory Pool Allocator: Efficient Memory Management Using Preallocated Memory Pools, Allocation Strategies, and Fragmentation Analysis.

## Purpose

This project demonstrates how memory allocation, deallocation, reuse, fragmentation, and pool management operate in user space. It focuses on practical C++ allocation logic rather than simulated bookkeeping.

## Main objectives

- Manage a reserved memory buffer.
- Provide fixed-size and variable-size allocations.
- Evaluate first-fit and best-fit strategies.
- Measure latency and throughput.
- Export actual benchmark data.
- Display allocator state through a lightweight dashboard.
